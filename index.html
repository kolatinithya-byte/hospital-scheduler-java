How It Works

1

Setup Database

Import SQL schema from /db folder. Configure DatabaseConfig.java with your credentials.

2

Build & Run Java Server

mvn clean compile && mvn exec:java - Server starts on localhost:8080 instantly.

3

Manage Staff & Shifts

Use REST APIs to add staff, create shifts, assign duties, and generate weekly rosters.
